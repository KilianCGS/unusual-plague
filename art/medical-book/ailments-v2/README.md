# Ailment engravings v2

Six revised illustrations generated with the built-in ChatGPT image tool.
They follow the approved ingredients and preparation drawings: warm brown ink,
clear naturalistic contours, sparse engraving hatching, no embedded text.

Runtime files: `public/game/ui/book/ailments/*-v2.png`.
The six original PNGs remain unchanged alongside them. No gameplay rules,
symptom descriptions or treatment descriptions were changed.

The white source paper is blended with multiply over the existing Book parchment.
The illustrations use smooth contain scaling in the original 176x176 slots.
Prompts and reference paths are recorded in `prompts.json`.

Subjects: fever, stomach discomfort, a bandaged work injury, chest cough,
scurvy/gums, exhaustion. The original open-wound proposal was rejected by the
image service; the final injury study uses a bandaged forearm instead.

Poisoning was subsequently added as a seventh ailment in `poisoning-v2.png`.
Its prompt is recorded separately in `poisoning-prompt.json`.

Review: `/dev/book` → **Ver las 7 dolencias**, then open the cover. These versions
are prepared for Kilian's visual review; no browser visual validation is claimed.
